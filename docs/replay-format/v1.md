# Replay format version 1

The base format.

## Layout

The file is the 4-byte header size, the [replay header](common.md#replay-header) with `version = 1`, then seven sections.

| Part | Layout |
|---|---|
| Section container | [12-byte container](common.md#12-byte-container-versions-1-6), one zstd frame per section |
| 1. Ticks | [Tick encoding](common.md#tick-encoding), flags below |
| 2. Tick subticks | [Fixed entries](common.md#fixed-entries-versions-1-6), 64 slots (1540-byte entries), one entry per tick |
| 3. Weapons | [Weapon table](common.md#weapon-table) |
| 4. Jumps | [Jump records](common.md#jump-records) with [84-byte AAData](common.md#jump-records) |
| 5. Events | [Raw 172-byte events](common.md#raw-events-versions-1-5) |
| 6. Commands | [Command encoding](common.md#command-encoding) |
| 7. Command subticks | [Fixed entries](common.md#fixed-entries-versions-1-6), 64 slots (1540-byte entries), one entry per command |

## Tick flags

Bits 0-38 are the [common change mask](common.md#change-mask). The remaining flags are:

| Bit | Flag |
|---|---|
| 39 | Weapon |

This version has no modern jump state: the tick state has no `modernJump` and the decoder skips that step.

## Notes

- Mode and style names in events are not always valid UTF-8, and events are not always in server tick order.
- Subtick angle deltas of analog steps are garbage and stand for 0.
