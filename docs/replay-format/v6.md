# Replay format version 6

Events become length-prefixed protobuf messages.

Changes from [version 5](v5.md):

- Events are length-prefixed `ReplayEvent` protobuf messages instead of 172-byte structs.

## Layout

The file is the 4-byte header size, the [replay header](common.md#replay-header) with `version = 6`, then seven sections.

| Part | Layout |
|---|---|
| Section container | [12-byte container](common.md#12-byte-container-versions-1-6), one zstd frame per section |
| 1. Ticks | [Tick encoding](common.md#tick-encoding), flags below |
| 2. Tick subticks | [Fixed entries](common.md#fixed-entries-versions-1-6), 36 slots (868-byte entries), one entry per tick |
| 3. Weapons | [Weapon table](common.md#weapon-table) |
| 4. Jumps | [Jump records](common.md#jump-records) with [92-byte AAData](common.md#jump-records) |
| 5. Events | [Protobuf events](common.md#protobuf-events-versions-6-7) |
| 6. Commands | [Command encoding](common.md#command-encoding) |
| 7. Command subticks | [Fixed entries](common.md#fixed-entries-versions-1-6), 36 slots (868-byte entries), one entry per command |

## Tick flags

Bits 0-38 are the [common change mask](common.md#change-mask). The remaining flags are:

| Bit | Flag |
|---|---|
| 39 | Weapon |
| 40 | Actual press |
| 41 | Usable press |
| 42 | Landed |

## Notes

- Subtick angle deltas of analog steps are garbage and stand for 0.
