# Replay format version 7

64-bit section headers, multi-frame sections and packed subticks.

Changes from [version 6](v6.md):

- Section headers are 24 bytes with 64-bit fields.
- A section payload can hold several zstd frames; long recordings write one frame per 15-minute chunk.
- Subtick entries are packed: a move count followed by that many moves.
- Subtick angle deltas are written for every step, analog steps included.

## Layout

The file is the 4-byte header size, the [replay header](common.md#replay-header) with `version = 7`, then seven sections.

| Part | Layout |
|---|---|
| Section container | [24-byte container](common.md#24-byte-container-version-7), one or more zstd frames per section |
| 1. Ticks | [Tick encoding](common.md#tick-encoding), flags below |
| 2. Tick subticks | [Packed entries](common.md#packed-entries-version-7), one entry per tick |
| 3. Weapons | [Weapon table](common.md#weapon-table) |
| 4. Jumps | [Jump records](common.md#jump-records) with [92-byte AAData](common.md#jump-records) |
| 5. Events | [Protobuf events](common.md#protobuf-events-versions-6-7) |
| 6. Commands | [Command encoding](common.md#command-encoding) |
| 7. Command subticks | [Packed entries](common.md#packed-entries-version-7), one entry per command |

## Tick flags

Bits 0-38 are the [common change mask](common.md#change-mask). The remaining flags are:

| Bit | Flag |
|---|---|
| 39 | Weapon |
| 40 | Actual press |
| 41 | Usable press |
| 42 | Landed |

## Notes

- Version 7 is not released yet. Its layout can still change before the first plugin release that writes it.
